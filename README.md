# DIKWP VerityWeave Semantic Resilience Grid OS

> **Reduce manipulation without censoring adverse truth.**

![SIRP-2000 L4 reference](assets/SIRP_2000_L4_REFERENCE_BADGE.svg)

VerityWeave is an English-only, offline-first, Apache-2.0 reference system for governing **semantic flows** rather than ranking people. It connects content, sources, counterevidence, context, incentives, audience conditions, interface design, recommender circulation, invited action, outcomes, appeals, and agent lineage in one inspectable workflow.

## Why it exists

The knowledge-abundant era does not suffer only from false statements. It also suffers from:

- true fragments stripped of conditions;
- uncertainty presented as certainty;
- prestige substituted for evidence;
- commercial funnels disguised as education;
- temporary vulnerability used as leverage;
- relationship advice converted into zero-sum identity conflict;
- interfaces designed to punish exit;
- opaque recommender amplification;
- corrections that never reach downstream recipients;
- policies and harmful methods inherited by successor agents.

VerityWeave does **not** treat sadness, anger, criticism, whistleblowing, satire, or bad news as inherently harmful.

## Direct use

Open the standalone application:

```text
DIKWP_VERITYWEAVE_SEMANTIC_RESILIENCE_GRID_OS_v2.0.0.html
```

No account, server, API key, or network connection is required.

## Install and run

```bash
python -m pip install -e .
verityweave demo --output .verityweave-demo --reset
```

Analyze a semantic flow:

```bash
verityweave analyze examples/parenting_sales_funnel.json \
  --output .verityweave-parenting \
  --ledger .verityweave-parenting/responsibility-ledger.jsonl
```

Audit an interface:

```bash
verityweave audit-interface examples/doomscroll_interface.json
```

Audit an agent lineage:

```bash
verityweave audit-lineage examples/agent_lineage_risk.json
```

Run the local API:

```bash
verityweave serve --host 127.0.0.1 --port 8765
```

Run the stateless MCP server:

```bash
verityweave mcp
```

## Eight competing worlds

Every analysis keeps multiple explanations alive:

1. bounded good faith;
2. good-faith compression;
3. negligent overclaim;
4. commercial manipulation;
5. coordinated deception;
6. satire or expressive speech;
7. protected adverse truth;
8. insufficient evidence.

Deliberate deception is not inferred from language style alone.

## Intervention ladder

```text
preserve protected expression
→ add context and sources
→ add reversible user-local friction
→ remove compulsive defaults locally
→ propose time-bounded circulation review
→ propose monetization disclosure gate
→ route imminent or unlawful harm to authorized human review
```

The reference core has:

```text
automatic content-removal authority = 0
automatic monetary-penalty authority = 0
automatic legal-determination authority = 0
automatic external-action authority = 0
```

## Positive Semantic Commons

High-integrity warnings, investigations, corrections, explainers, translations, and public-interest records can receive transparent support proposals. Support does not depend on ideological agreement or positive sentiment.

## Appeals and correction

A wrong decision remains open until five receipts exist:

```text
RESTORE_ACCESS_OR_OPPORTUNITY
CORRECT_ORIGINAL_RECORD
NOTIFY_DOWNSTREAM_RECIPIENTS
COMPENSATE_VERIFIED_LOSS
REVISE_OR_RETIRE_RULE_OR_MODEL
```

## Agent-lineage governance

The lineage audit covers shared memory, hidden communication, inherited artifacts, policy drift, successor reuse, control-plane access, stop propagation, audit gaps, human reporting, and self-repairing persistence.

## Runtime constitution

```text
Negative affect alone never triggers restriction.
Criticism is not harm.
Whistleblowing is not malice.
Vulnerability is temporary and contextual, not a permanent person label.
Deliberate deception is not inferred without independent evidence.
High-impact adverse actions require named human authority.
Every adverse action requires notice, reasons, expiry, appeal, correction, and restoration.
Automatic content removal authority = 0.
Automatic external action authority = 0.
```

## Status

```text
RESEARCH_ALPHA_REFERENCE_IMPLEMENTATION
```

VerityWeave is not a universal fact checker, intent detector, addiction diagnosis, legal decision system, or certified moderation service. Its protocol mappings are unsigned references. Production use requires multilingual evaluation, human-rights and data-protection assessment, independent appeals, security review, and measurable real-world outcomes.
