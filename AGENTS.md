# Agent instructions

1. Preserve the distinction between negative affect and semantic harm. Negative tone, criticism, whistleblowing, satire, grief, and distress must not independently trigger restriction.
2. Analyze behavior and circulation, not a person's moral worth, intelligence, political reliability, or mental state.
3. Do not infer deliberate deception without independent evidence.
4. Keep user-local actions reversible. Platform-level adverse actions remain human-gated proposals with notice, reasons, expiry, appeal, correction, and restoration.
5. Do not add network clients, automatic deletion, remote publication, account sanctions, payment actions, or secret cross-agent memory to the reference core.
6. Retain adverse evidence, minority hypotheses, failed tests, and limitations.
7. Run `make test`, `make audit`, and `make model-check` before proposing a release.
